## Sobre

DevReport e uma ferramenta de analise de produtividade para equipes de desenvolvimento.
Gera dashboards com metricas de issues, pull requests e insights de IA.

## Estrutura de Branches

Cada branch neste repositorio corresponde a uma task do projeto, vinculada a um card no Kanban.

| Formato | Exemplo |
|---------|---------|
| 	ask/TASK-NNN-slug | 	ask/TASK-001-criar-projeto-spring-boot |
